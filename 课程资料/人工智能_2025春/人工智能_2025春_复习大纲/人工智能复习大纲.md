### 2.3 命题逻辑 (Propositional Logic) ⭐

#### 基本概念
- **命题** (Proposition): 具有确定真值的陈述句（True/False）
- **原子命题**: 不可再分的命题
- **复合命题**: 由原子命题通过联结词组合

#### 语法 (Syntax)
1. 命题常量 True(T) 和 False(F) 是公式
2. 命题变元 P, Q, R, ... 是公式
3. 若 A 是公式，则 (¬A) 是公式
4. 若 A, B 是公式，则 (A∧B), (A∨B), (A→B), (A↔B) 是公式
5. 有限次应用以上规则得到的都是公式

#### 逻辑联结词
| 联结词 | 符号 | 含义 |
|--------|------|------|
| 否定 | ¬ | NOT |
| 合取 | ∧ | AND |
| 析取 | ∨ | OR |
| 蕴含 | → | IF...THEN (等价于 ¬P∨Q) |
| 双条件 | ↔ | 当且仅当 (P→Q)∧(Q→P) |

#### 语义 (Semantics)
- **指派** (Assignment): 给每个命题变元赋予真值 T 或 F
- n 个命题变元有 2ⁿ 种可能的指派
- 对任意公式 A，指派 φ 下 A 的真值记为 φ(A)

#### 重要概念
- **永真式** (Tautology): 在所有指派下均为真
- **可满足式** (Satisfiable): 存在某指派使其为真
- **不可满足式** (Unsatisfiable): 所有指派下均为假
- **逻辑等价** (Equivalence): A ≡ B，当且仅当 A↔B 为永真式
- **逻辑蕴涵** (Entailment): A ⊨ B，当且仅当 A→B 为永真式

#### 范式
- **合取范式** (CNF): 子句的合取，如 (P∨Q∨R)∧(¬P∨Q)
- **析取范式** (DNF): 文字的合取的析取
- 任一命题公式都可等价转换为 CNF 或 DNF

### 2.4 命题演算 (Propositional Calculus, PC)

#### 公理系统
- **AX1**: A → (B → A)
- **AX2**: (A → (B → C)) → ((A → B) → (A → C))
- **AX3**: (¬A → ¬B) → (B → A)
- **推理规则 (MP)**: 由 A 和 A→B 可推出 B

#### 核心定理
- **可靠性** (Soundness): 若 PC ⊢ A，则 ⊨ A（可证的必为真）
- **完备性** (Completeness, Gödel 1929): 若 ⊨ A，则 PC ⊢ A（为真的必可证）
- **一致性** (Consistency): 不存在公式 A 使得 PC ⊢ A 且 PC ⊢ ¬A
- **演绎定理** (Deduction Theorem): {A} ⊢_PC B 当且仅当 ⊢_PC A→B

### 2.5 一阶谓词逻辑 (First-Order Logic, FOL)

#### 为什么需要 FOL？
- 命题逻辑表达能力有限（不能表达"所有"、"存在"等量词关系）
- 如 "所有人都会死" 无法在命题逻辑中简洁表达

#### 语法新增元素
- **个体词**: 常量 (a, b, c, ...)、变量 (x, y, z, ...)
- **谓词** (Predicate): P(x), Q(x,y), 表示个体的属性或关系
- **函数** (Function): f(x), g(x,y), 映射个体到个体
- **全称量词** (∀): ∀x P(x) — "对所有 x"
- **存在量词** (∃): ∃x P(x) — "存在 x"

#### 例子
- "凡是青蛙都是绿色的": ∀x (Frog(x) → Green(x))
- "有人喜欢猫": ∃x Likes(x, cat)
- "所有人喜欢猫": ∀x Likes(x, cat)

#### 量词辖域与变量
- 自由变量 vs 约束变量
- 量词对偶性: ¬∀x P(x) ≡ ∃x ¬P(x); ¬∃x P(x) ≡ ∀x ¬P(x)

### 2.6 置换 (Substitution) ⭐

**定义**: σ = {t₁/x₁, t₂/x₂, ..., tₙ/xₙ}，其中 xᵢ 为变量，tᵢ 为项

**应用**: Eσ 表示将表达式 E 中的每个 xᵢ 同时替换为 tᵢ

**示例**:
- P(x) {apple/x} = P(apple)
- Likes(x, icecream) {John/x} = Likes(John, icecream)

### 2.7 FOL 推理规则

| 规则 | 形式 |
|------|------|
| 假言推理 | P, P→Q ⇒ Q |
| 全称例示 (UI) | ∀x P(x) ⇒ P(y) (y 为任意项) |
| 存在例示 (EI) | ∃x P(x) ⇒ P(y) (y 为新常量) |

### 2.8 形式证明实例

**例题**: 给定以下前提，证明 ∃x (G(x) ∧ ¬D(x))
1. ∀x (G(x) → A(x) ∨ B(x) ∨ C(x))
2. ∀x (G(x) ∧ D(x) → ¬A(x))
3. ∀x (G(x) → ¬B(x) ∧ ¬C(x))

（详细证明步骤见课件，涉及全称例示、假言推理等规则）

## 第三、四讲：知识表示与推理 II —— 归结原理

### 3.1 命题逻辑（回顾与深化）

> 本讲承接第二讲，重点在归结原理这一自动定理证明方法

#### 逻辑联结词（复习）
- **否定** (¬): NOT
- **合取** (∧): AND
- **析取** (∨): OR
- **蕴含** (→): IF...THEN，等价于 ¬P ∨ Q
- **双条件** (↔): 当且仅当

#### 重要概念
- **合式公式** (WFF): Well-Formed Formula
- **永真式** (Tautology): 在所有解释下均为真
- **等价** (Equivalence): P ≡ Q
- **可满足性** (Satisfiability)
- **逻辑蕴涵** (Entailment): KB ⊨ α — 在所有使 KB 为真的模型中，α 也为真

### 3.2 一阶谓词逻辑 (FOL)（深化）

#### 语法元素
- **常量** (Constants): a, b, c, ...
- **变量** (Variables): x, y, z, ...
- **谓词** (Predicates): P(x), Q(x,y), R(x,y,z), ...
- **函数** (Functions): f(x), g(x,y), ...
- **全称量词** (∀): "对所有 x"
- **存在量词** (∃): "存在 x"
- **项** (Term): 常量、变量或函数作用于项

#### 重要概念
- **自由变量** vs **约束变量**
- **量词辖域** (Scope)
- **解释** (Interpretation) 与 **模型** (Model)
- **KB ⊨ α**: 知识库 KB 蕴涵公式 α
- **可靠性** (Soundness): KB ⊢ α ⇒ KB ⊨ α
- **完备性** (Completeness): KB ⊨ α ⇒ KB ⊢ α

### 3.3 归结原理 (Resolution Principle) ⭐

> J.A. Robinson, 1965 — 自动化定理证明的核心方法

#### 子句形式 (Clause Form)
- **文字** (Literal): 原子公式或其否定
- **子句** (Clause): 文字的析取
- **合取范式** (CNF): 子句的合取
- **空子句** (NIL): 代表矛盾/假

#### 命题归结规则
```
给定: C₁ = L ∨ C₁'
      C₂ = ¬L ∨ C₂'
归结: C = C₁' ∨ C₂'   （归结式 Resolvent）
```
- L 和 ¬L 为**互补文字**
- C₁ 和 C₂ 为**父子句**

#### 反证法证明步骤
1. 将 ¬α 加入 KB（否定目标）
2. 将 KB ∪ {¬α} 化为子句集 S
3. 反复应用归结规则导出新子句
4. 若导出 **NIL**，则原命题得证（反证法）

#### 归结策略
| 策略 | 特点 |
|------|------|
| **水平饱和** (Level Saturation) | 逐层生成所有归结式，完备但低效 |
| **支撑集策略** (Set of Support) | 至少一个父辈来自目标否定，完备且聚焦 |
| **线性归结** (Linear Resolution) | 每次使用最新导出的子句，命题逻辑中完备 |
| **输入归结** (Input Resolution) | 一个父辈来自原始子句集，不一定完备 |

#### 答案提取 (Answer Extraction)
- 添加 `¬Goal(x) ∨ Answer(x)` 到子句集
- 归结导出 NIL 时读取 Answer(…) 中的绑定

### 3.4 合一算法 (Unification) ⭐

#### 置换 (Substitution)
- σ = {t₁/v₁, t₂/v₂, ..., tₙ/vₙ}
- 应用: Eσ = 将 E 中的每个 vᵢ 同时替换为 tᵢ
- 组合: σθ = 先应用 σ 再应用 θ
- σθ ≠ θσ（一般不可交换）

#### MGU (最一般合一)
- σ 是 MGU 当且仅当：对任何其他合一 θ，存在 λ 使得 θ = σλ
- **合一算法步骤**:
  1. k=0, Fₖ=F, σₖ=ε（空置换）
  2. 若 Fₖ 为单元素集（所有表达式相同），返回 σₖ
  3. 找 Fₖ 的**分歧集 Dₖ**
  4. 在 Dₖ 中找变量 xₖ 和项 tₖ（**occurs check**: xₖ 不出现于 tₖ）
  5. Fₖ₊₁ = Fₖ{tₖ/xₖ}, σₖ₊₁ = σₖ ∘ {tₖ/xₖ}, k=k+1，转步骤2
  6. 若找不到，报告**不可合一**

### 3.5 子句形转换 (Skolem 化) ⭐

将任意 FOL 公式转化为 CNF 子句集的完整流程：

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1 | 消去 → | P→Q → ¬P∨Q |
| 2 | 缩小 ¬ 辖域 | De Morgan 定律 |
| 3 | 变量标准化 | 每个量词使用不同变量名 |
| 4 | **Skolem 化** | 消去 ∃: 若在 ∀x₁...∀xₙ 辖域内，用 Skolem 函数 f(x₁,...,xₙ) 替换；否则用 Skolem 常量 |
| 5 | 移至前束范式 | 所有 ∀ 移至最前 |
| 6 | 分配 ∨ 对 ∧ | 化 CNF |
| 7 | 省略 ∀ | 化为子句集 |
| 8 | 再次变量标准化 | 各子句变量名独立 |

## 第五、六讲：搜索技术 I —— 盲目搜索与启发式搜索

### 3.1 搜索问题形式化

#### 五要素
1. **状态空间** (State Space): 所有可能状态
2. **动作/后继函数** S(x): 从状态 x 可执行的操作
3. **初始状态** (Initial State)
4. **目标条件** (Goal Test)
5. **启发式函数** h(n)（用于启发式搜索）

#### 解的定义
从初始状态到目标状态的动作序列

#### 典型例题
- **罗马尼亚旅行**: Arad → Bucharest，状态=城市，动作=驾车
- **水壶问题**: 3加仑和4加仑水壶，状态=(gal3, gal4)
- **八数码** (8-Puzzle): 3×3 滑块拼图
- **吸尘器世界**: 8个房间，left/right/suck 动作

### 3.2 Frontier（Open List）与搜索框架

- **Frontier** = 待扩展节点的集合
- 初始：Frontier = {初始状态}
- 每步：从 Frontier 取一节点 → 扩展 → 子节点加入 Frontier
- **关键**: Frontier 的**选择顺序**决定了求解与否、解的质量、时空复杂度

#### 路径检查 vs 循环检查
- **路径检查**: 仅检查当前路径上是否出现重复
- **循环检查**: 维护 Closed 表，记录所有已扩展节点

### 3.3 盲目搜索策略

| 算法 | Frontier 顺序 | 完备性 | 最优性 | 时间复杂度 | 空间复杂度 |
|------|--------------|--------|--------|------------|------------|
| **BFS** 广度优先 | FIFO 队列 | ✅ | ✅(等代价) | O(bᵈ⁺¹) | O(bᵈ⁺¹) |
| **DFS** 深度优先 | LIFO 栈 | ❌(可循环) | ❌ | O(bᵐ) | O(bm) |
| **UCS** 一致代价 | 按 g(n) 优先 | ✅ | ✅ | O(b^(C*/s+1)) | O(b^(C*/s+1)) |
| **DLS** 深度限制 | DFS+L限深 | ❌ | ❌ | O(bᴸ) | O(bL) |
| **IDS** 迭代加深 | 重复DLS递增L | ✅ | ✅(等代价) | **O(bᵈ)** | **O(bd)** |
| **Bidirectional** | 双向搜索 | ✅ | ✅ | O(b^(d/2)) | — |

> 符号: b=分支因子, d=最浅目标深度, m=最大深度, L=深度限制, C*=最优解代价, s=最小步代价

#### BFS 详细分析
- 逐层扩展，Frontier: {0} → {1,2} → {2,2,3} → ...
- 时间: 1+b+b²+...+bᵈ+b(bᵈ-1) = O(bᵈ⁺¹)
- 空间: b(bᵈ-1) = O(bᵈ⁺¹)
- 示例: b=10, d=6 → 18分钟, 111MB; d=8 → 31小时, 11GB

#### DFS 详细分析
- 时间: O(bᵐ)，空间: **O(bm)**（主要优势）
- 不完备（若状态空间含环）
- DLS 伪代码:
  ```
  若 Depth(n) < D: Frontier = (Frontier \ {n}) ∪ Successors(curr)
  否则: Frontier = Frontier \ {n}, CutOffOccured = TRUE
  ```

#### IDS = DFS 空间 + BFS 完备性
- 时间: (d+1)b⁰ + d·b¹ + (d-1)·b² + ... + bᵈ = **O(bᵈ)**
- 仅比 BFS 略慢，但空间为 O(bd)

### 3.4 启发式搜索

#### Greedy Best-First Search
- f(n) = **h(n)**（仅启发式）
- 扩展"看起来最近的"节点
- ❌ 不完备，不保证最优

#### A* 搜索 ⭐
- f(n) = **g(n) + h(n)**
  - g(n) = 从起点到 n 的实际代价
  - h(n) = 从 n 到目标的启发式估计
  - f(n) = 经过 n 的最优解的估计代价
- 统一了 UCS（优化 g）和 Greedy（优化 h）

#### A* 最优性条件

**1. 可采纳性 (Admissibility)**
- h(n) ≤ h*(n)，对所有 n（永不高估真实代价）
- h(n)=0 总是可采纳的（退化为 UCS）
- 可采纳性 ⇒ A* 最优

**2. 一致性/单调性 (Consistency/Monotonicity)**
- h(n₁) ≤ c(n₁, n₂) + h(n₂)（三角不等式）
- 一致性 ⇒ 可采纳性（更强条件）
- 一致性 ⇒ f 值沿路径非递减

#### A* vs IDA*
- A* 需要存储所有节点（空间大）
- **IDA*** = 迭代加深 + A*（用 f=g+h 作为截断值）
- 每次迭代提高截断值至上次超过的最小 f 值

### 3.5 启发式设计：八数码

| 启发式 | 定义 | 性质 |
|--------|------|------|
| h₁ | 不在位棋子数 | 可采纳 |
| h₂ | **曼哈顿距离** (各棋子到目标位置水平和垂直距离之和) | 可采纳, **h₂ 支配 h₁** |

#### 性能对比（展开节点数）
| 深度 | IDS | A*(h₁) | A*(h₂) |
|------|-----|--------|--------|
| 10 | 47,127 | 93 | 39 |
| 14 | 3,473,941 | 539 | 113 |
| 24 | — | 39,135 | 1,641 |

> **结论**: 更好的启发式（支配性越强）极大缩减搜索空间。

### 4.2 博弈基本概念

- **零和博弈**: 一方所得即另一方所失
- **MAX 节点**: 我方行动，选择最大值
- **MIN 节点**: 对方行动，选择最小值
- **终局状态**: 已知效用值
- **博弈树**: MAX 和 MIN 交替的树结构

### 4.3 MiniMax 算法

```
DFMiniMax(n, Player):
  If n is TERMINAL: Return U(n)
  ChildList = Successors(Player)
  If Player is MIN: return minimum of DFMiniMax(c, MAX)
  Else: return maximum of DFMiniMax(c, MIN)
```

**性质**:
- ✅ 对完美对手最优
- 时间: O(bᵈ), 空间: O(bd)
- 国际象棋: b≈35, d≈50 ⇒ 完全不可行

### 4.4 Alpha-Beta 剪枝 ⭐

**核心思想**: 剪除不影响最终决策的分支

- **α** (Alpha): MAX 目前已见的最佳选择值（下界）。初始 = -∞
- **β** (Beta): MIN 目前已见的最佳选择值（MAX 的上界）。初始 = +∞
- **剪枝条件**: 若 α ≥ β，剪枝（停止搜索该分支）

**效率**:
- 最优排序下: O(b^(d/2)) — 相当于搜索深度翻倍
- Deep Blue: 实际分支因子从 35 降至 ~6

### 4.5 评估函数与资源限制

- 不能搜索到终局时：使用**评估函数**评估非终局局面
- **深度是关键**: 评估函数藏在越深处，其质量影响越小
- **迭代加深**: 持续加深搜索直到时间耗尽
- 国际象棋评估: 兵=1, 马/象=3, 车=5, 后=9, Deep Blue 用~8000个特征

### 4.6 蒙特卡洛树搜索 (MCTS)

**四阶段循环**:
1. **选择** (Selection): 用 UCB1 公式从根节点选择到未扩展节点
2. **扩展** (Expansion): 加入一个新子节点
3. **模拟** (Simulation/Rollout): 随机下到终局
4. **回传** (Backpropagation): 更新访问次数和胜率

### 4.7 AlphaGo 架构

**训练三阶段**:
1. **行为克隆** (Supervised Learning): 用人类棋谱初始化策略网络（交叉熵损失）
2. **策略梯度** (RL): 策略网络自我对弈（REINFORCE, 赢+1/输-1）
3. **价值网络** (Regression): 预测状态价值 V(s)

**执行**: MCTS 结合策略网络和价值网络

## 第八讲：高级搜索技术 —— 局部搜索与优化

### 5.1 局部搜索概述

- 不关心到达解的路径，只关心解的**状态本身**
- 适用于**优化问题**：在状态空间中寻找最优状态
- 不维护 Frontier/Closed 表，内存开销极低

### 5.2 爬山算法 (Hill-Climbing)

```
function Hill-Climbing(problem):
    current = Make-Node(Initial-State[problem])
    loop:
        neighbor = highest-valued successor of current
        if Value[neighbor] < Value[current]:
            return State[current]    // 到达局部最优
        current = neighbor
```

**特点**:
- 贪心策略，选择最佳后继
- ❌ 不保证全局最优（陷入局部极值、高原、山脊）
- **变体**: 随机爬山、首选爬山、随机重启爬山

### 5.3 模拟退火 (Simulated Annealing)

- Kirkpatrick et al., 1983 (Metropolis, 1953)
- 模拟金属退火过程，允许以一定概率接受更差的解
- 接受概率: **Boltzmann 分布** e^(-ΔE/T)
- **温度 T** 从高到低逐渐下降（冷却计划）
- 高温时探索空间广，低温时收敛到最优

**参数**:
- 初始温度、冷却率、终止温度
- 适用于 **NP 难** 问题的近似求解

### 5.4 八数码问题与启发式

- h₁ = 不在位棋子数
- h₂ = 曼哈顿距离 (Manhattan distance)
- 曼哈顿距离对八数码始终 ≥ 不在位数

- 爬山算法的伪代码与局限性

## 第十讲：决策树

### 7.1 决策树算法家族

| 算法 | 发明者/年份 | 特征 |
|------|-----------|------|
| **CLS** | Hunt, Marin, Stone, 1966 | 概念学习系统，最早 |
| **ID3** | Quinlan, 1979/1986 | 信息增益 |
| **C4.5** | Quinlan, 1993 | 增益率 (Gain Ratio) |
| **CART** | Breiman et al., 1984 | Gini 指数 |

### 7.2 决策树基本概念

- **节点**: 对应一个属性测试
- **分支**: 对应属性的可能取值
- **叶节点**: 对应分类结果
- **构建**: 递归选择最优划分属性
- **剪枝**: 防止过拟合

### 7.3 信息熵 (Entropy)

$$
H(X) = -\sum_{i=1}^{n} P(x_i) \log_2 P(x_i)
$$

- 衡量随机变量的不确定性
- 对于二分类: H(p) = -p·log₂(p) - (1-p)·log₂(1-p)
- p=0.5 时熵最大 (1 bit)

### 7.4 条件熵与互信息

**条件熵**:
$$
H(Y|X) = \sum_x P(x) \cdot H(Y|X=x)
$$

**互信息 (信息增益)**:
$$
I(X;Y) = H(Y) - H(Y|X) = H(X) - H(X|Y)
$$

- ID3 使用信息增益选择划分属性
- 问题: 偏向取值多的属性

### 7.5 C4.5 — 增益率 (Gain Ratio)

$$
\text{GainRatio}(A) = \frac{\text{Gain}(A)}{\text{SplitInfo}(A)}
$$

$$
\text{SplitInfo}(A) = -\sum_{v=1}^{V} \frac{|D_v|}{|D|} \log_2\left(\frac{|D_v|}{|D|}\right)
$$

- 解决了信息增益偏向多值属性的问题

### 7.6 CART — Gini 指数

$$
\text{Gini}(D) = 1 - \sum_{k=1}^{K} p_k^2 = \sum_{k=1}^{K} p_k(1-p_k)
$$

- 衡量数据集的纯度/不纯度
- 选择使 Gini 指数最小的属性
- 支持二叉分裂

### 7.7 连续值处理

- 排序后取相邻值中点作为候选分裂点
- 常用策略: **二分法** (取中值)，即选取第 (vᵢ+vᵢ₊₁)/2 个候选点

- 能手工计算信息熵、信息增益、增益率、Gini 指数
- 理解 ID3/C4.5/CART 的区别与联系
- CLS 算法基本流程
- 理解决策树构建与剪枝

## 第十二讲：无监督学习 —— 聚类

### 9.1 聚类基本概念

**目标**: 组内距离最小化，组间距离最大化

**应用**: 市场细分、文档聚类、降水模式发现、行业分组

### 9.2 聚类类型分类

| 分类维度 | 类型 |
|----------|------|
| 是否划分 | **划分聚类** (Partitional) vs **层次聚类** (Hierarchical) |
| 隶属关系 | **硬聚类** vs **模糊/概率聚类** (每个点以权重属于各类) |

**簇的类型**:
- 分离良好的簇 (Well-Separated)
- 中心型簇 (Center-based)
- 连续型簇 (Contiguous)
- 密度型簇 (Density-based)
- 概念/属性型簇 (Conceptual)

### 9.3 K-means 算法 ⭐

**算法步骤**:
1. 随机选择 K 个初始中心
2. 将每个点分配给最近的中心
3. 重新计算每个簇的中心（均值）
4. 重复 2-3 直到收敛

**复杂度**: O(n·K·I·d)

**目标函数 — SSE (误差平方和)**:
$$
\text{SSE} = \sum_{i=1}^{K} \sum_{x \in C_i} \text{dist}^2(m_i, x)
$$

**K 值选择**:
- **肘部法则** (Elbow Method): 画 SSE-K 曲线，找"肘点"

**改进**:
- **K-means++**: 用 D(x)² 加权采样初始中心（保证 O(log k) 近似比）
- **K-means||**: 并行初始化

**局限**: 不同大小/密度/非球形/含离群点的聚类效果差

### 9.4 DBSCAN 算法 ⭐

**核心定义**:
- **核心点** (Core Point): Eps 邻域内 ≥ MinPts 个点
- **边界点** (Border Point): 在核心点邻域内但不满足 MinPts
- **噪声点** (Noise): 既非核心也非边界

**算法**:
1. 对每个未访问的核心点，创建一个新簇
2. 将该核心点的所有密度可达点加入簇
3. 标记非核心非边界点为噪声

**优点**: 抗噪声、处理任意形状簇、不需指定 K
**局限**: 变化密度和高维数据效果差

**参数选择**: k-dist 图（第 k 近邻距离排序图）找拐点

### 9.5 K-means vs DBSCAN

| 特性 | K-means | DBSCAN |
|------|---------|--------|
| 噪声处理 | 使用所有数据 | 丢弃噪声 |
| 类型 | 基于原型 | 基于密度 |
| 簇形状 | 各向同性 | 任意形状 |
| K 值 | 需预设 | 自动确定 |

### 9.6 聚类评估

- **外部指标**: 与真实标签比较（熵）
- **内部指标**: SSE、轮廓系数
- TSS = SSE + SSB（总平方和 = 组内 + 组间，为常数）

## 第十三讲：人工神经网络

### 10.1 生物启发

- 大脑 ~1000 亿神经元
- 神经元结构: 树突 → 细胞体 → 轴突

### 10.2 MP 神经元 (McCulloch-Pitts, 1943)

$$
z = \sum_i w_i \cdot a_i = \mathbf{w}^T \mathbf{a}
$$

$$
\text{output} = \text{sgn}(z) = \begin{cases} 1, & z \geq 0 \\ -1, & z < 0 \end{cases}
$$

- 最早的人工神经元模型
- **Hebb 学习规则** (1949): "一起放电的神经元连在一起" (Cells that fire together, wire together)

### 10.3 感知机 (Perceptron)

- MP 神经元的可学习版本
- 单层输出，学习规则: w ← w + (y - ŷ)·x
- **Minsky 1969**: 感知机不能解决 **XOR** 问题（线性不可分）
- 权重定义超平面: wᵀa = 0

### 10.4 多层感知机 (MLP) ⭐

**架构**: 输入层 → 隐藏层(≥1) → 输出层

$$
\mathbf{y} = \sigma_2(\mathbf{W}_2 \cdot \sigma_1(\mathbf{W}_1 \cdot \mathbf{x} + \mathbf{b}_1) + \mathbf{b}_2)
$$

- 可解决 XOR 问题

### 10.5 激活函数

| 函数 | 公式 | 导数 | 使用场景 |
|------|------|------|----------|
| **sgn** | sgn(x) = {1, x≥0; -1, x<0} | 0 (除原点) | MP 神经元 |
| **Sigmoid** | σ(x) = 1/(1+e⁻ˣ) | σ(x)(1-σ(x)) | 早期 MLP |
| **tanh** | tanh(x) = (eˣ-e⁻ˣ)/(eˣ+e⁻ˣ) | 1-tanh²(x) | DNN |
| **ReLU** | max(0, x) | {0, x<0; 1, x>0} | 现代 DNN |

### 10.6 万能逼近定理

> 含单隐层的前馈网络可以逼近任何连续函数 (Cybenko 1989, Hornik et al. 1989)

### 10.7 前向传播计算示例

给定输入 a₁=0.05, a₂=0.10, 偏置 b=0.35, 权重 w:
- z₁ = w₁·a₁ + w₂·a₂ + b (隐层求和)
- o₁ = σ(z₁) (Sigmoid 激活)
- Loss: L = ½ Σ(target - output)²

### 10.8 反向传播 (Backpropagation) ⭐

Rumelhart, Hinton, 1986

**链式法则**:
$$
\frac{\partial L}{\partial w} = \frac{\partial L}{\partial o} \cdot \frac{\partial o}{\partial z} \cdot \frac{\partial z}{\partial w}
$$

**Sigmoid 导数**: ∂σ/∂z = σ(z)·(1 - σ(z))

**权重更新**: w⁽ⁿᵉʷ⁾ = w⁽ᵒˡᵈ⁾ - η · ∂L/∂w

### 📝 复习要点

- MP 神经元模型
- XOR 问题的线性不可分性
- MLP 架构与前向传播公式

$$
\mathbf{y} = \sigma_L(\mathbf{W}_L \cdots \sigma_2(\mathbf{W}_2 \cdot \sigma_1(\mathbf{W}_1\mathbf{x} + \mathbf{b}_1) + \mathbf{b}_2) \cdots + \mathbf{b}_L)
$$

### 11.2 ImageNet 竞赛历程

| 年份 | 模型 | 层数 | Top-5 错误率 |
|------|------|------|-----------|
| 2012 | AlexNet | 8 | 16.4% |
| 2014 | VGG | 19 | 7.3% |
| 2014 | GoogleNet (Inception) | 22 | 6.7% |

**2018 图灵奖**: Bengio, Hinton, LeCun（深度学习先驱）

### 11.3 CNN（卷积神经网络）⭐

#### 为什么 CNN？
- MLP 将所有像素独立处理 → 忽略空间结构
- CNN **参数共享**（权重在空间位置间共享）→ 大幅减少参数

#### 核心操作

**1. 卷积 (Convolution)**:
- 滤波器/卷积核 (Filter/Kernel) 在图像上滑动
- 输出特征图 (Feature Map)
- 步长 (Stride) = 1 或 2

**2. Padding**:
- **Same**: 输出尺寸 = 输入尺寸 / 步长
- **Valid**: 无填充
- 输出尺寸 = (n - f + 2p)/s + 1

**3. 最大池化 (Max Pooling)**:
- 降采样操作
- 在每块区域内取最大值
- 典型模式: Conv → MaxPool → Conv → MaxPool → ... → FC → Output

#### CNN vs MLP 对比
- CNN: 局部连接 + 参数共享 → 参数少
- MLP: 全连接 → 参数多

### 11.4 RNN（循环神经网络）

**目的**: 处理序列数据（文本、语音、时间序列）

$$
h_t = f(\mathbf{W} \cdot h_{t-1} + \mathbf{U} \cdot x_t + b)
$$

$$
y_t = \mathbf{V} \cdot h_t
$$

**BPTT** (Back-Propagation Through Time): 梯度沿时间反向传播

#### 梯度消失/爆炸问题
- w=0.99, w¹⁰⁰⁰ → 0（消失）
- w=1.01, w¹⁰⁰⁰ → 20000（爆炸）
- 对策: **梯度裁剪** (Gradient Clipping)

### 11.5 LSTM（长短期记忆网络）⭐

**四个门控 + 记忆单元**:

| 组件 | 作用 |
|------|------|
| **遗忘门** (Forget Gate) | 决定丢弃哪些旧信息 |
| **输入门** (Input Gate) | 决定存储哪些新信息 |
| **输出门** (Output Gate) | 决定输出什么 |
| **记忆单元 cₜ** | 长期记忆通道 |

- 门控用 **Sigmoid** (0~1)，候选值用 **tanh** (-1~1)
- 有效缓解梯度消失问题

### 11.6 其他主题

- **对抗样本** (Adversarial Examples): 深度网络容易被微小扰动欺骗
- **可解释 AI** (Explainable AI): 局部解释（为什么这张图是猫？）vs 全局解释（猫在模型眼中什么样？）
- **生成模型**: GAN, VAE 等
- **关键架构**: Transformer, BERT, ChatGPT, AlphaFold

## 第十五讲：深度学习 II —— Transformer

### 15.1 自然语言处理 (NLP) 基础

#### 为什么 NLP 需要特殊处理？
- 语言的离散性和组合性
- 同义词、多义词、语境依赖
- 长距离依赖关系

#### 早期方法
- **WordNet**: 人工构建的词汇数据库（同义词集、上位词 "is-a" 关系）
  - ❌ 问题: 覆盖不全、无法捕捉语境、维护成本高

### 15.2 词嵌入 (Word Embedding)

#### One-Hot 编码的问题
- motel = [0,0,...,0,1,0,...,0]，维度 = 词汇量 (50万+)
- ❌ **无法度量相似性**: "motel" 和 "hotel" 的 one-hot 向量正交

#### 分布式语义假说 (Distributional Hypothesis)
> "You shall know a word by the company it keeps." — J.R. Firth, 1957

- 核心思想: 词的含义由其**上下文**决定
- 通过统计词共现关系学习**稠密向量表示**（50-300维）

### 15.3 SVD 词向量

- 构建**共现矩阵**: 统计词对的窗口内共现次数
- 对共现矩阵做 SVD 分解降维
- 通过 LLE 等算法可视化

### 15.4 Word2Vec ⭐

> Mikolov et al., 2013 — "Distributed Representations of Words and Phrases"

#### 核心思想
- 训练模型根据上下文预测目标词（或反过来）
- 学习到高质量的低维词向量

#### CBOW (Continuous Bag of Words)
- **任务**: 用上下文词窗口预测中心词
- 输入: 上下文词的 one-hot 向量
- 过程: 上下文向量平均 → 隐藏层 → Softmax 输出目标词概率
- 架构: Input(HV×1) × W(|V|×N) → Hidden(N) × W'(N×|V|) → Output(|V|×1)
- 损失: 交叉熵 (Cross Entropy)

#### Skip-Gram
- **任务**: 用中心词预测上下文词窗口
- 与 CBOW 相反: "输入 → 周围词"
- 对于罕见词效果更好

#### 关键发现
- **king - man + woman ≈ queen**（词向量可做类比推理）
- 词向量捕捉语法和语义规律

#### 局限性
- 每个词只有一个向量，无法处理一词多义
- 如 "read" → "reading", "reader", "readable" 在 Word2Vec 中无关联

### 15.5 GloVe 与 FastText

#### GloVe (Global Vectors for Word Representation)
- 结合**全局统计信息**（共现计数）和**局部上下文窗口**
- 在共现矩阵上做矩阵分解

#### FastText (Facebook, 2016)
- 基于**子词 (subword)** 的 CBOW
- 将词拆分为 n-gram 字符序列
- 可处理 **OOV** (Out-of-Vocabulary) 词

### 15.6 机器翻译 (Machine Translation)

#### 方法演变
| 年代 | 方法 | 特点 |
|------|------|------|
| 1990s-2010s | **SMT** (统计机器翻译) | 短语对齐、语言模型，需要大量特征工程 |
| 2014-2016 | **NMT** (神经机器翻译) | Seq2Seq+RNN，端到端训练 |
| 2016+ | NMT 超越 SMT | *NYT* 报道 "The Great AI Awakening" |

### 15.7 Seq2Seq (Encoder-Decoder) ⭐

#### 架构
```
Encoder (编码器): 输入 x → 中间表示 (context vector)
Decoder (解码器): 中间表示 → 输出 y
```

#### 核心思想
- Encoder 将可变长输入压缩为固定长度的**上下文向量**
- Decoder 从上下文向量生成可变长输出

#### 应用
- 机器翻译 (MT)
- 文本摘要 (Summarization)
- 对话生成 (Dialogue)
- NL2SQL
- 代码生成

### 15.8 注意力机制 (Attention) ⭐

#### 为什么需要 Attention？
- ❌ Encoder-Decoder 的**瓶颈**: 所有信息压缩到单个固定长度向量
- ✅ Attention: 允许 Decoder 在每一步**动态关注**输入的不同部分

#### Attention 三步计算
1. **相似度计算**: eᵢ = similarity(query, keyᵢ)，常用点积 score(q,k) = q·k
2. **归一化**: αᵢ = softmax(e₁,...,eₙ)（注意力权重，和为1）
3. **加权求和**: context = Σ αᵢ · vᵢ

#### QKV 框架
- **Query** (查询): 当前想知道什么（Decoder 状态）
- **Key** (键): 输入的索引（Encoder 各位置）
- **Value** (值): 输入的内容（Encoder 各位置）
- 输出 = Σ (Query 与 Key 的相似度) × Value

#### Seq2Seq + Attention
- Decoder 每个时刻计算当前状态与所有 Encoder 状态的注意力
- 动态加权上下文向量参与解码

### 15.9 Transformer ⭐⭐⭐

> Vaswani et al., 2017 — "**Attention Is All You Need**"
> 彻底取代 RNN/CNN 成为 NLP 和更多领域的核心架构

#### Transformer 相比 RNN 的三大优势

| 优势 | RNN | Transformer |
|------|-----|-------------|
| **计算复杂度** | O(n) 序列依赖（不可并行） | n<<d 时每层复杂度低 |
| **长距离依赖** | 信息需经过 O(n) 步传递 | 自注意力 O(1) 直连任意位置 |
| **并行化** | 序列依赖无法并行 | 完全可并行（GPU/TPU 友好） |

#### 自注意力 (Self-Attention) 核心公式

**步骤 1 — 生成 QKV**:
$$
Q = XW^Q, \quad K = XW^K, \quad V = XW^V
$$
其中 X ∈ ℝ^(n×d)，W^Q, W^K, W^V ∈ ℝ^(d×dₖ)

**步骤 2 — 计算注意力分数**:
$$
\text{Score} = QK^T
$$

**步骤 3 — Scaled Dot-Product 归一化**:
$$
\text{Attention}(Q,K,V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right) \cdot V
$$
- 除以 √dₖ 避免点积值过大导致 softmax 梯度消失

**步骤 4 — 加权输出**:
$$
\text{Output} = \text{Attention}(Q,K,V)
$$

#### 三大关键技巧 (Three Tricks)

**Trick #1: 残差连接 (Residual Connections)**
$$
X^{(l)} = \text{Layer}(X^{(l-1)}) + X^{(l-1)}
$$
- 缓解深层网络梯度消失问题
- 平滑 Loss Landscape

**Trick #2: 层归一化 (Layer Normalization)**
- 对每个样本的特征维度归一化（均值=0, 方差=1）
- 加速训练，稳定梯度

**Trick #3: Scaled Dot-Product Attention**
- 如前所述，除以 √dₖ 防止 Softmax 区域饱和

#### 多头注意力 (Multi-Head Attention)
- 并行运行 **h 个**自注意力头（h 个不同的 W^Q, W^K, W^V）
- 各头关注不同的语义关系
- 拼接各头输出: MultiHead = Concat(head₁, ..., headₕ) · W^O
- 每个头的维度 dₖ = d/h

#### 位置编码 (Positional Encoding)
- Transformer 无循环结构 → 无法感知位置信息
- **解法**: 在输入嵌入中加上**正弦位置编码** (Sinusoidal Positional Encoding)
- 不同频率的正弦/余弦函数 → 唯一的位置表示
- 或使用可学习的位置嵌入

#### Transformer 整体架构

```
编码器 (Encoder): N× 层
  每层: Multi-Head Self-Attention → Add&Norm → FFN → Add&Norm

解码器 (Decoder): N× 层
  每层: Masked Multi-Head Self-Attention → Add&Norm
       → Cross-Attention (Q from Decoder, K,V from Encoder) → Add&Norm
       → FFN → Add&Norm
```

- **Masked Self-Attention**: 防止 Decoder 看到未来信息（训练时）
- **Cross-Attention**: Decoder 的 Q 去查询 Encoder 的 K,V

### 15.10 Transformer 的影响

#### Scaling Law
- 模型参数量、数据量、计算量 → 性能可预测增长
- 催生 GPT、BERT、LLaMA、DeepSeek 等大模型

#### 超越 NLP
- **ViT** (Vision Transformer): 图像识别
- **AlphaFold**: 蛋白质结构预测
- **多模态**: CLIP, DALL·E, GPT-4V

- 理解分布式语义假说和 Word2Vec (CBOW/Skip-Gram)
- 掌握 Attention 机制的 QKV 框架和计算
- ⭐ **Transformer Self-Attention 公式**（核心考点）
- 理解 Multi-Head Attention 和 Positional Encoding
- Seq2Seq + Attention → Transformer 的演进逻辑
- 三大 Tricks 的作用

## 第十六讲：强化学习

### 12.1 强化学习定义

> Sutton 定义: "RL 是关于学习做什么——如何将状态映射到动作——以最大化数值奖励信号的问题"

**RL 三大特点**:
1. 本质上是**闭环**的（行动影响后续输入）
2. **没有直接指示**应该采取什么行动
3. 行动的后果（包括奖励信号）在**延长时间段**内展开

### 12.2 RL 核心组件

```
Environment  ──Reward (R)──→  Agent
    ↑                            ↓
    └──── State (S) ←────────── Action (A)
```

- **状态 Sₜ**: 当前环境状态
- **动作 Aₜ**: Agent 的行为
- **奖励 Rₜ**: 即时反馈信号
- **策略 π(a|s)**: 状态到动作的映射（可为随机策略）
- **折扣因子 γ ∈ [0,1]**: 未来奖励的折扣

**奖励假设**: 所有目标都可以通过最大化期望累积奖励来描述

### 12.3 马尔可夫决策过程 (MDP) ⭐

**MDP 五元组**: ⟨S, A, P, R, γ⟩

- **转移概率**: P(s'|s,a) = Pr{Sₜ₊₁ = s' | Sₜ = s, Aₜ = a}
- **马尔可夫性质**: 未来仅依赖于当前状态和动作，与历史无关

### 12.4 值函数

**回报 (Return)**:
$$
G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + \cdots = \sum_{k=0}^{\infty} \gamma^k R_{t+k+1}
$$

**状态价值函数 V(s)**:
$$
V_\pi(s) = \mathbb{E}_\pi[G_t | S_t = s]
$$

**动作价值函数 Q(s,a)**:
$$
Q_\pi(s,a) = \mathbb{E}_\pi[G_t | S_t = s, A_t = a]
$$

**V 与 Q 的关系**:
$$
V_\pi(s) = \sum_a \pi(a|s) \cdot Q_\pi(s,a)
$$
$$
Q_\pi(s,a) = R(s,a) + \gamma \sum_{s'} P(s'|s,a) \cdot V_\pi(s')
$$

### 12.5 Bellman 方程 ⭐

**Bellman 期望方程**:
$$
V_\pi(s) = \sum_a \pi(a|s) \left[ R(s,a) + \gamma \sum_{s'} P(s'|s,a) \cdot V_\pi(s') \right]
$$

**Bellman 最优方程**:
$$
V^*(s) = \max_a \left[ R(s,a) + \gamma \sum_{s'} P(s'|s,a) \cdot V^*(s') \right]
$$
$$
Q^*(s,a) = R(s,a) + \gamma \sum_{s'} P(s'|s,a) \cdot \max_{a'} Q^*(s',a')
$$

### 12.6 动态规划方法

| 方法 | 说明 |
|------|------|
| **策略评估** (Policy Evaluation) | 给定 π，迭代计算 V(s) |
| **策略改进** (Policy Improvement) | π'(s) = argmax_a Q_π(s,a) |
| **策略迭代** (Policy Iteration) | 交替 评估 → 改进 至收敛 |
| **值迭代** (Value Iteration) | Vₖ₊₁(s) = max_a [R + γ Σ P·Vₖ(s')] |

### 12.7 无模型方法

#### 蒙特卡洛 (MC) 方法
- 从完整 Episode 中学习
- V(s) = 从状态 s 开始的回报平均值
- 高方差、无偏

#### 时序差分 (TD) 学习
**TD(0)**:
$$
V(S_t) \leftarrow V(S_t) + \alpha [R_{t+1} + \gamma V(S_{t+1}) - V(S_t)]
$$
- TD 目标: Rₜ₊₁ + γV(Sₜ₊₁)
- TD 误差: δₜ = Rₜ₊₁ + γV(Sₜ₊₁) - V(Sₜ)
- 结合 MC 和 DP 的优点

### 12.8 SARSA (On-Policy) vs Q-Learning (Off-Policy) ⭐

| 特性 | SARSA | Q-Learning |
|------|-------|------------|
| 类型 | On-Policy | Off-Policy |
| 更新 | Q(s,a) ← Q + α[r + γQ(s',a') - Q] | Q(s,a) ← Q + α[r + γ·**maxₐ**Q(s',a) - Q] |
| 行为策略 | ε-greedy（探索中学习） | ε-greedy（探索） |
| 目标策略 | 同行为策略 | 贪心策略（最优） |

### 12.9 深度强化学习 (DRL)

#### DQN (Deep Q-Network)
- 用 DNN 近似 Q 函数
- **经验回放** (Experience Replay): 存储 (s,a,r,s')，随机采样打破相关性
- **目标网络** (Target Network): 单独的网络计算目标值，定期更新

**DQN 变体**:
- **Double DQN**: 解耦动作选择与评估，减少过估计
- **Dueling DQN**: Q(s,a) = V(s) + A(s,a)，分离状态价值与优势
- **Rainbow DQN**: 组合六种改进

#### 策略梯度 (Policy Gradient)
- 直接参数化并优化策略 π_θ(a|s)
- **REINFORCE**: θ ← θ + α·∇_θ log π(a|s)·Gₜ
- 减基线 (Baseline) 降低方差

#### Actor-Critic 方法
- **Actor** (策略网络): 决定动作 π_θ(a|s)
- **Critic** (价值网络): 评估动作 V_w(s) 或 Q_w(s,a)
- **A2C** (Advantage Actor-Critic): 用优势函数 A(s,a) = Q(s,a) - V(s)

### 12.10 AlphaGo / AlphaGo Zero

**训练三阶段**（已在第七讲详述）:
1. 监督学习初始化
2. 强化学习自我对弈
3. 价值网络回归

**MCTS 执行**: 选择 (UCB) → 扩展 → 评估 (快速走子+价值网络) → 回传

**AlphaGo Zero**: 零人类知识，100-0 击败原 AlphaGo

### 12.11 强化学习方法总结

| 类别 | 代表算法 |
|------|----------|
| 基于价值 (Value-based) | DQN, Double DQN, Dueling DQN, Rainbow |
| 基于策略 (Policy-based) | REINFORCE |
| Actor-Critic | A2C, A3C |
| 基于模型 vs 无模型 | — |
| On-Policy vs Off-Policy | SARSA vs Q-Learning |

### 📝 复习要点

- MDP 五元组定义
- V(s), Q(s,a) 定义与关系
- **Bellman 期望方程与最优方程**（核心公式）
- TD 更新公式与 TD 误差
- **SARSA vs Q-Learning 的区别**（On-policy vs Off-policy）
- DQN 的经验回放与目标网络
- Actor-Critic 基本架构
- AlphaGo 的训练流程

- Bellman 最优: V*(s) = max_a [R + γ Σ P·V*(s')]
- TD 更新: V(s) ← V(s) + α[R + γV(s') - V(s)]
- Q-Learning: Q(s,a) ← Q(s,a) + α[R + γ·max_a' Q(s',a') - Q(s,a)]
